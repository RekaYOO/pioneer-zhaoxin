## 题目概述

你需要学习并使用UDP、TCP、HTTP三种协议，编写一个Python客户端程序，按照特定的流程与服务器进行通信，完成一系列交互任务。若你初次接触相关内容，观察服务器的响应内容是至关重要的，保存响应内容并且不断调试对于完成本题有很大帮助。如果你无法完成整道题目，不用担心，任何的探索都是有价值的，我们记录下了你发出的每一次通信内容，这都会成为你的加分点。

## 通信流程

### UDP

你需要通过UDP协议向服务器发送你的学号，获取一个会话标识符。

**请求格式**：
```json
{
    "type": "get_session",
    "student_id": "2025xxxx"
}
```

**成功响应格式**：
```json
{
    "success": true,
    "session_id": "uuid字符串",
    "message": "sessionid获取成功"
}
```

### TCP

使用第一阶段获得的标识符，通过TCP协议与服务器建立连接并接收数据。

**连接请求**：
```json
{
    "type": "tcp_connect",
    "session_id": "从UDP阶段获得的session_id"
}
```

**连接成功响应**：
```json
{
    "success": true,
    "message": "TCP连接成功"
}
```

**流式数据类型**：
在TCP连接建立后，服务器会发送多种类型的JSON消息，每个消息以换行符(`\n`)分隔：

1. **开始**：
```json
{"type": "stream_start", "message": "开始流式传输"}
```

2. **字符**：
```json
{"type": "stream_char", "char": "c", "position": "0"}
```

3. **结束**：
```json
{"type": "stream_end", "message": "流式传输完成"}
```

4. **断开**：
```json
{"type": "disconnect_request", "message": "断开连接确认"}
```

**断开确认**：
当收到断开确认请求时，你需要发送：
```json
{
    "type": "disconnect_confirm",
    "message": "客户端确认断开连接"
}
```

### HTTP POST

通过HTTP POST请求向服务器确认你的完成情况。

**请求格式**：
```json
{
    "nickname": "你的昵称",
    "student_id": "你的学号"
}
```
